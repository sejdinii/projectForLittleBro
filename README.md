# 🏆 The Little Bro Awards 2026

A fake award ceremony website dedicated to roasting my little brother.

**Live:** https://sejdinii.github.io/projectForLittleBro/

## Files

- `index.html`: the entire site (single file, no dependencies)

## Deploy your own

1. Fork or copy this repo.
2. Go to **Settings → Pages**.
3. Set the source to **Deploy from a branch** → `master` / `root`.
4. The site goes live at `https://<username>.github.io/<repo-name>/`.
